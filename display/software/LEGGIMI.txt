BRACCIO ROBOTICO - OPZIONE DISPLAY LCD 16x2
===========================================
Articolo completo: https://www.emgi.it/2026/10/19/braccio-robotico-telecamera-raspberry-pi-stampato-3d/

Il modo piu' semplice per installare tutto e' farsi guidare da Claude (claude.ai o Claude Desktop):
allegagli questo zip, o i singoli file, e chiedigli le procedure un passo alla volta.
Claude legge i file, ti dice cosa scrivere e controlla con te il risultato.
Esempio: "Ho collegato il display LCD al braccio: aiutami a installare display_lcd.py e a provarlo."

COSA C'E'
---------
display_lcd.py        mostra posizione dei giunti e luce; server HTTP sulla porta 8092 per i messaggi
                      (GET /lcd?r1=Ciao&r2=Mondo&sec=10 - lo usano Claude e il controller)
display-lcd.service   avvio automatico

INSTALLAZIONE
-------------
1. I2C attivo (sudo raspi-config -> Interface Options -> I2C) e: sudo apt install -y python3-smbus2 i2c-tools
2. sudo cp display_lcd.py /opt/braccio/ ; sudo cp display-lcd.service /etc/systemd/system/
3. sudo systemctl daemon-reload ; sudo systemctl enable --now display-lcd
4. Prova: i2cdetect -y 1 -> 40 (PCA9685) e 27 o 3f (display). Contrasto: trimmer blu sul modulo I2C.
Serve braccio_web.py attivo (pacchetto del braccio).
