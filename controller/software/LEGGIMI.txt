BRACCIO ROBOTICO - OPZIONE CONTROLLER REMOTO (Arduino Nano + 2 joystick + 4 pulsanti)
===================================================================================
Articolo del braccio: https://www.emgi.it/2026/10/19/braccio-robotico-telecamera-raspberry-pi-stampato-3d/

Il modo piu' semplice per installare tutto e' farsi guidare da Claude (claude.ai o Claude Desktop):
allegagli questo zip, o i singoli file, e chiedigli le procedure un passo alla volta.
Claude legge i file, ti dice cosa scrivere e controlla con te il risultato.
Esempio: "Ho montato il controller del braccio: aiutami a caricare lo sketch sul Nano e a installare controller_braccio.py."

COSA C'E'
---------
arduino/console_braccio/console_braccio.ino   sketch del Nano: manda "J,a0,a1,a2,a3,pulsanti" a 115200 baud
raspberry/controller_braccio.py               legge il Nano via USB e muove il braccio (API di braccio_web.py)
raspberry/controller-braccio.service          avvio automatico

INSTALLAZIONE
-------------
1. Carica lo sketch sul Nano con l'IDE Arduino (scheda "Arduino Nano"; per i cloni CH340 a volte serve
   "ATmega328P (Old Bootloader)").
2. Sul Pi: sudo apt install -y python3-serial
3. sudo cp raspberry/controller_braccio.py /opt/braccio/ ; sudo cp raspberry/controller-braccio.service /etc/systemd/system/
4. sudo systemctl daemon-reload ; sudo systemctl enable --now controller-braccio
5. Collega il Nano a una porta USB del Pi. Log: journalctl -u controller-braccio -f

COMANDI
-------
Joystick sinistro: X = base, Y = spalla. Joystick destro: Y = gomito.
Pulsanti: tilt su / giu, rotazione sinistra / destra.
Pulsante del joystick sinistro: breve = STOP, tenuto 2 s = HOME base. Pulsante del joystick destro: luce.
Se un giunto va al contrario: cambia il segno in SEGNO all'inizio di controller_braccio.py.
Se c'e' anche il display LCD, mostra STOP, HOME e luce.
